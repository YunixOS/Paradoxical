# Paradoxical
Create Clausewitz Engine mods using TypeScript.

Paradoxical provides a TypeScript API for constructing and serializing
Clausewitz data files, allowing mods to be generated programmatically.

## Features
- Generate mod files within JS/TS.
- Generate localisation files using JS/TS (W.I.P (soon™)).
